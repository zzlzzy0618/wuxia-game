## 简介

大江东去，浪淘尽，千古风流人物。魔教"日月神宗"卷土重来，江湖血雨腥风。你是江南小镇一介布衣少年，机缘巧合习得武学残卷，今日仗剑出门——从江南市井，到华山之巅、大漠戈壁、嵩山少林、海外移花岛，直至决战黑木崖，书写属于你的江湖传说。

**🎮 在线游玩**：[https://zzlzzy0618.github.io/wuxia-game/](https://zzlzzy0618.github.io/wuxia-game/)

**无需安装、无需联网**：整个游戏构建为一个 `index.html` 文件，双击用浏览器打开即玩，进度自动保存在浏览器本地。

## 玩法特性

### 世界
- **十大门派**：少林（金刚不坏）、武当（真气回复）、古墓（灵动闪避）、飞刀门（例无虚发）、移花宫（明玉吸血）、丐帮（醉侠血性）、桃花岛（奇门遁甲）、灵鹫宫（天池真气）、大理段氏（皇族血脉）、白云城（紫禁之巅），各有独立成长曲线与专属被动
- **201 门武学**：门派专精 150 + 秘籍通用 20 + 隐世绝学 30（九阳神功、北冥神功、独孤九剑……），含连击、会心、震慑、吸血、破防、必中必暴等机制
- **304 件物品**：12 类武器 × 6 阶（含倚天剑、屠龙刀等神兵）、8 类防具、7 类饰品、丹药、锻造材料、珍宝、秘籍
- **54 张地图**：江南、中原、塞北、西域、川蜀、岭南、海外等 8 大地域，随主线逐一开启，每张地图有独立敌人池、头目与风物志
- **10 章主线 + 8 位支线头目**：从怒惩恶霸到决战魔教教主，每个头目都有专属剧情演出

### 伙伴
- **16 名伙伴**：剧情结识、地图寻访、银两雇请等多种招募方式
- 伙伴随行参战、拥有独立成长与专属绝技，可上阵最多 2 名
- 特殊伙伴提供被动加成（悬赏加成、商店折扣、锻造成功率等）

### 养成与玩法
- **悬赏榜**：定期刷新的讨伐任务，赚取银两与声望
- **锻造强化**：精钢升星，武器护甲强化至 +5
- **比武大会**：三战夺魁，赢取限定称号
- **称号成就**：击杀数、头目数、财富等维度解锁称号，自动佩戴最强称号
- **奇遇系统**：探索中触发隐世武学、珍宝与特殊事件
- 打坐修炼、客栈歇息、飞鸽购药、采药炼丹一应俱全

### 表现
- 水墨视觉：宣纸质感 UI、朱砂印章、楷体排印
- WebAudio API 实时合成音效，无任何外部资源（可静音）

## 快速开始

```bash
git clone https://github.com/<你的用户名>/wuxia-game.git
cd wuxia-game
# 用浏览器打开 index.html 即可游玩
start index.html   # Windows
open index.html    # macOS
```

或者直接把 `index.html` 下载到本地双击打开。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 探索 | 在当前地图随机遭遇：战斗 / 拾遗 / 采药 / 见闻（可触发奇遇） |
| 挑战头目 | 推进主线的关键战斗，誓死一战不可逃跑 |
| 启程·地图 | 前往已解锁的其他地图 |
| 悬赏榜 | 接取并讨伐悬赏目标 |
| 锻造铺 | 消耗矿石强化武器护甲 |
| 比武大会 | 报名参赛，三战夺魁 |
| 伙伴 | 查看已招募伙伴，随行或歇息 |
| 打坐修炼 | 花费银两换取经验，有小概率走火入魔 |
| 客栈歇息 | 花费银两全恢复气血内力 |
| 飞鸽购药 | 远程购买丹药与装备 |
| 行囊 / 武学 | 服用丹药、装备武器、查看武学 |

**新人提示**：先在江南探索练到 3 级、买几颗金创药，再去挑战镇关西；战斗中内力不足时可用普通攻击过渡，善用门派绝学的特殊效果；遇到瓶颈可招募伙伴共同作战。

## 开发与测试

源码采用模块化结构，`node build.js` 将 `src/` 下模块按序拼接为单文件 `index.html`：

```
wuxia-game/
├── build.js            # 构建脚本（拼接 src/ → index.html）
├── index.html          # 游戏本体（构建产物，可直接游玩）
├── src/
│   ├── 00_head.html    # HTML 结构与样式
│   ├── 01_core.js      # 工具函数与音效合成
│   ├── 02_data_sects.js# 十大门派与武学模板
│   ├── 03_data_items.js# 物品基础数据
│   ├── 04_data_world.js# 地图、剧情、头目
│   ├── 05_gen.js       # 武学/物品/敌人生成器
│   ├── 06_state.js     # 状态管理与存档
│   ├── 07_battle.js    # 战斗引擎
│   ├── 08_systems.js   # 悬赏/锻造/比武/称号系统
│   ├── 09_ui.js        # 界面渲染
│   └── 10_main.js      # 主流程逻辑
├── test/
│   ├── smoke.test.js   # 冒烟与平衡性测试
│   └── tune.js         # 平衡性调参脚本
├── README.md
└── LICENSE
```

```bash
node build.js           # 构建
node test/smoke.test.js # 冒烟测试
```

### 平衡性测试

冒烟测试在无浏览器环境下模拟全部游戏逻辑，覆盖：

- 数据完整性（10 门派 / 201 武学 / 304 物品 / 54 地图 / 16 伙伴及其交叉引用校验）
- 建号、升级、存档流程
- 悬赏 / 商店 / 锻造 / 伙伴 / 称号系统功能
- 自动战斗胜率（12 组门派 × 头目对局，每组 60 场模拟，目标区间 55%–99%）
- 伙伴参战对胜率的影响
